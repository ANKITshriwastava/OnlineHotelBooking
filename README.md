
# Online Hotel Booking System

A full-stack hotel booking web application inspired by Booking.com.

## Features
- User Authentication
- Hotel Search & Booking
- Currency Selection
- Responsive UI
- Booking Management
- Secure Backend APIs

## Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- Thymeleaf
- REST API

## Project Status
Currently under development.
